# F01–F04 Implementation Plan

> Execution: parallel implementation with isolated file ownership, followed by integration and independent review. Follow test-driven-development and verification-before-completion.

**Goal:** 完成搜索筛选、分类、账户转账、导出及备份的可用前后端。
**Architecture:** 扩展现有 domain/store/api；派生账户余额；原生小程序；独立备份服务。
**Tech Stack:** Go、MySQL、JavaScript/WXML/WXSS、shell/Python tests。
**Spec:** ../specs/2026-10-23-p0-ledger-design.md
