## 范围

48 个线性图标（24 默认＋24 扩展），可编辑 SVG 源素材、字体与预览；iconfont 优先，加载失败回落 Emoji。统一琥珀底，动态线稿颜色和选中态。分类编辑器同时支持线稿与 Emoji；内置与用户分类均可选择。覆盖分类、记账、账单/详情、搜索、日历、统计和预算。

保持 009 的 id 或 name 双锚、kind、账本1和 BINARY 旧值条件，消费同时支持有无 FE0F。已有他人调整不覆盖，复核实际文件，不以 Notion 的测试描述代替执行。

## 数据与接口

新增 010：t_categories.icon_key 可空，已知 key 校验；icon 保留回退。为保证一键操作只影响内置分类，新增只读 system_icon_key 标识默认分类角色，用户创建不能写入；图标编辑不改变该标识。旧数据通过 ID/名称识别一个默认角色的唯一行（优先已知 ID，再历史同名种子），歧义时保守跳过，不标记所有同名分类。可识别的用户自定义图标只记录系统角色，不自动替换 icon_key。

POST /api/v1/categories/system-icons 在当前认证账本事务内将已标识的内置分类 icon_key 统一为其 system_icon_key，保留 icon 回退和其他字段；不接收分类 ID 列表，不操作自建分类，重复调用无副作用。成功失效分类缓存。

PATCH：icon_key 缺省保留；空字符串或 null 显式切回 Emoji；旧客户端仅提交 icon 时清空 icon_key；同时提交有效 icon_key 和 icon 可保持双轨；名字/排序/停用更新不改变图标。

## 交互

顶部 banner 仅在内置角色仍显示 Emoji 时显示“ N 个分类仍使用 Emoji 图标”和“统一为系统图标”；可关闭，按用户/账本/本次小程序版本持久化忽略状态。不启动弹窗。点击后按 Notion 指定文案二次确认，确认后才请求批量接口；取消不修改。自建分类不计数、不统一。
