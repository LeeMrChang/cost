# 移除账单导出设计

用户于 2026-11-11 明确要求移除 Cost 的导出账单功能。本说明在功能代码修改前建立；前端和后端测试断言已先行调整，未将其描述为设计批准或完整 Superpowers 流程。

## 目标与非目标

移除设置页导出入口、小程序 CSV 获取、写入及分享逻辑、后端 CSV 接口和专属编码逻辑。保留账单查询、分类、账户、转账、服务端数据库备份与恢复。

## 数据、接口与权限

不修改数据模型、数据库结构或迁移，不操作真实数据。删除 `GET /api/v1/entries/export` 的路由；旧路径落入现有 `/entries/{id}` 路由并返回 400 `invalid_entry`，不再返回 CSV。现有认证与单用户单账本权限保持不变。

## 验收标准

- 设置页无导出入口、事件处理器，小程序 API 不再提供 CSV 导出。
- 后端无 CSV 导出处理器、公式转义、50001 条专用查询分支；旧路径不再导出。
- 相关测试更新并通过；README、接口说明和验证记录同步更新。
- 历史设计与验证事实保留，注明功能已移除。

## 风险与验证

旧版小程序调用旧接口将失败，发布时应同步更新两端。运行前端全量测试、后端 race 测试、vet 和构建。无认证、SQL 或迁移变更，不需要新增 MySQL 集成测试；未运行的 MySQL 和微信验证单独记录。

## 流程缺口

当前环境未找到 using-superpowers、brainstorming、writing-plans、test-driven-development、requesting-code-review 或 verification-before-completion 技能文件；不声称已执行这些技能。用户已明确授权移除功能，没有另行设计审批或独立审查证据。
