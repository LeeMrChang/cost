# 底部导航图标设计

用户要求按截图为“账本”“统计”补上图标。采用现有原生 tabBar，在 `miniprogram/app.json` 配置本地 PNG 的 iconPath、selectedIconPath。

账本使用带文字线条的线框账本，统计使用三根递增圆角实心柱。透明背景，81×81 像素；未选中 #8B9199、选中 #3B82F6，与现有导航文字一致。只修改视觉资源与配置，不改变导航、数据、接口、权限和数据库。

验收：两项均配置普通和选中图标；四张 PNG 有效、本地路径存在；前端测试、语法和页面检查通过。微信开发者工具与真机效果需单独验证。

当前环境未找到 using-superpowers、brainstorming 等项目要求技能，未执行技能规定的设计评审或独立审查。用户已明确图标样式和修改范围，当前代理直接执行；不声称完整遵循 Superpowers。此说明在配置和图片写入后补录。
