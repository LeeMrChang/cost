# 账本首页优先显示用户头像

2026-11-04。用户明确要求首页右上角展示微信上传的头像，无头像才显示默认图标；沿用当前功能分支与 PR #13，不额外确认执行方式。

- 复用现有用户 avatar_url、api.me 和 profile.avatarView，不改变后端或数据库。
- 首页先显示当前会话已缓存头像，并在刷新/从设置返回时读取最新资料。服务端明确返回空头像时清除旧图，回退到现有账本图标（初始默认 📒）。
- 用户资料请求失败时保留本次当前会话缓存值，不阻断账单加载。页面重新加载先清除非当前会话头像，旧加载结果由已有 loadVersion 拦截。
- 原位置保持 64rpx 圆形、点击进入设置；有图显示 aspectFill 图片，无图或当前图片读取失败则显示账本图标。旧图片迟到的错误事件不能清除新头像。
- 验收：有/无头像、从设置返回后换头像、切账号清空、资料失败、图片失败回退与迟到事件；Node 全套、页面检查、独立审查和 PR CI。真机视觉验收未执行时明确记录。
