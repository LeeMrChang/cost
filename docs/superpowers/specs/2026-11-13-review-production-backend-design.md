# 审核登录使用生产接口

## 证据与原因

审核反馈登录无法使用；截图出现开发环境地址。当前配置在 envVersion=develop 时默认选择回环地址，这个行为在手机上无法连接部署服务。无法确认审核设备实际返回的 envVersion 或当时上传的代码；修复不依赖这两个假设。2026-11-13 从本机访问生产 /health 得到 HTTP 200、证书校验成功、status=ok、auth_mode=wechat；尚未完成真实微信登录。

## 行为

- 仅 envVersion=develop 且 platform=devtools 默认使用 http://127.0.0.1:8081，其余环境（含手机开发预览、体验版、正式版与无法识别的环境）使用 https://api.xiachen.xyz。
- 仅 envVersion=develop 且 platform=devtools 时允许读取新手动保存的 cost_devtools_base_url，并展示调试地址表单。
- 旧 cost_base_url 缓存不再读取；升级后开发者工具默认连接本地接口，仅需自定义端口或连接云端时才手动设置。
- Android、iOS、桌面微信等真实客户端不读取调试地址缓存，不展示或执行保存调试地址操作。
- 设备识别优先使用 wx.getDeviceInfo，旧基础库可通过 wx.getSystemInfoSync 识别；无法确定设备时按生产行为处理。
- 本地模拟器默认使用 127.0.0.1:8081，可手动覆盖；手机预览默认连接生产服务。本次不增加手机端隐藏调试入口。

## 范围与权限

只修改小程序公开配置和登录页调试入口，不修改后端、认证、数据库、AppID 或密钥；不部署，不上传，不代替用户提交审核。现有会话和业务数据结构不变。

## 验证

先添加并运行环境/登录页回归，证明旧代码在开发版手机场景下误用本地地址。修改后运行小程序完整测试与语法检查。公网检查只访问健康接口及未认证接口，不读取业务数据。微信开发者工具、真实 wx.login、安卓真机以及平台合法域名配置必须分别验收，不能用单元测试代替。
