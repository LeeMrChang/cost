# iCost v4.3 主流程修复设计（补录）

日期：2026-10-26。依据：用户确认执行前的只读排查、cost_need 下 V2.1.3 与 v4.3。本文补录本轮实施边界，不替代原需求的 P1/P2 分期。

目标：保留现有去家庭化改造，修复记账和查账的数据安全问题，对齐全屏键盘、详情、搜索和预算主流程。

- 记账：真实 tap 事件不能被解释为继续记账；编辑后再记切为新增；停用的原分类可保留；无页面传参时按 ID 读取，失败时禁止保存；清空输入后金额归零。
- 编辑 API：账户、退款关联、报销、排除统计/预算与货币字段缺省时保留旧值；显式传值可修改。其余原有必填字段仍按完整编辑请求校验。
- 详情：新增 GET 单笔接口；首页、搜索、日历统一进入详情，编辑返回后重读。
- 删除：006 显式迁移新增 deleted_at；列表、统计、搜索、账户余额排除软删除账单；5 秒内 POST restore 可恢复，超时 409。删除保留幂等键，重复创建不得复活旧账单。
- 前端：共享撤销组件在来源页显示提示；搜索进入空态、清空时取消旧请求、详情返回或后台恢复时刷新；日历按所选日期隔离异步请求并读取全部分页。
- 预算：返回所有支出分类及 is_set，未设置分类预算也显示真实支出；进度 >80% 黄、超支红；首页未设预算不标记超支。
- 周统计归零到周一零点；暂保留既有 ISO 周预算键，日历仍按周日起展示。计算器保留先乘除后加减；中文输入保留键盘，提交搜索后收起。

不纳入本轮：退款业务、模板、标签、报销统计、图片、完整图表体系、周/年预算 UI 和真实库部署。相关入口明确提示后续版本支持。

数据库升级必须先备份；本轮不修改真实业务库。MySQL 隔离验证受本环境 socket 权限限制；原生编译不能代替微信视觉和真机验收。
