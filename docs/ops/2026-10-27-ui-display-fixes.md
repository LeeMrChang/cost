# 第一批 UI 缺陷修复（展示层）

> 公开文档脱敏说明（2026-11-18）：个人路径、部署标识及真实账本数据已省略或改为占位示例。历史验证结论保留，不代表使用占位示例重新执行。示例路径使用前须替换；部署脚本的内置默认路径以源码为准，本次未调整脚本。

分支 `fix/ui-defects`，依据 2026-10-27 确认的第一批缺陷：③ 日历万元金额裁切、④ 胶囊遮挡标题/头像、⑤ 千分位与结余 ¥、⑥ 月份补零、⑧ 日历重复月份标题。均为展示层修正，不改数据结构与接口字段。

## 改动

- 新增 `displayMoney`（`miniprogram/utils/money.js`）：仅用于展示，输出千分位与两位小数，负数带 `-`；计算器输入与编辑框仍用 `money`，避免把逗号带进输入。
- ③ 日历格子：金额字号 18rpx→16rpx、容器改为占满格宽并 `overflow:hidden`，带千分位的大额收入完整显示（真实金额省略）；未使用负字距（负字距会让小数点在高分屏消失）。
- ④ 明细页自定义导航：按 `wx.getMenuButtonBoundingClientRect()` 计算右侧留白（`navRight`），标题单行省略，头像与菜单不再进入胶囊区域。
- ⑤ 明细/日历/统计/搜索/预算/账户/详情所有金额展示改用 `displayMoney`；明细页结余补 `¥`，负结余显示为 `-¥x`。
- ⑥ 后端月标签 `2006年01月`→`2006年1月`，与需求文档 `2026年10月` 写法一致。
- ⑧ 日历页不再把原生导航标题改成月份，原生标题保留「收支日历」，页内只显示一处月份。
