## 升级与手工验收

新增 `006_entry_soft_delete.sql`。**未执行本地或云端业务库迁移**。未升级 006 的数据库不能运行这版 SQL 查询，可能报 `Unknown column deleted_at`。

1. 先在隔离数据库运行包含迁移恢复、软删除、账户余额及合并护栏的完整测试（backend 目录）：

   ```sh
   COST_TEST_MYSQL_ADMIN_DSN='root@unix(/tmp/mysql.sock)/' go test -race -count=1 ./...
   ```

   测试创建并清理随机 `cost_test_*` 库，不使用业务库。
2. 备份并核实业务库后，用有 DDL 权限的迁移账号执行 `go run ./cmd/api -migrate`。本机应用账号没有 DDL 权限，迁移命令和连接示例见 README；随后以应用账号启动。
3. 微信开发者工具核对：完成返回来源、连续两笔新增、编辑后再记不覆盖、账户保留、详情删除与撤销、搜索返回刷新、日历收支同时显示、分类预算未设置时仍显示支出。
